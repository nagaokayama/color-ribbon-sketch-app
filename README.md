# color ribbon sketch

好きなグラデーションカラーで絵を描けるブラウザのお絵かきアプリ。

いい感じの名称を考え中です。

[アプリを開く](https://nagaokayama.github.io/color-ribbon-sketch-app/)

## カラーセット

- ベース・影・ハイライトと中間色をまとめた5色のセット。
- カラーセットの追加・削除・セット名の変更が可能。

カラーセットのうち、直接色を指定できるのは真ん中のカラーのみです。
左右にある4色は影色、ハイライト色の変化の傾向をスライダーで調整することで自動的に設定されます。

## 描画

- ツールはペン、消しゴム、スポイト
- 最大10操作の取り消し・やり直し。
- 最前面・中間・背面の3レイヤー。左のレイヤーメニューで描画先を選択する。

各レイヤーの絵は独立しており、消しゴムは選択中のレイヤーだけを消去する。
取り消し・やり直しでは、操作したレイヤーが選択される。目のボタンで表示・非表示を切り替え、スポイトとPNG保存には表示中のレイヤーを重ねた画像を使う。

ローカルで試す場合は、`dist/index.html` をブラウザで開く。


## 画像の保存

1024×1024pxのPNGで書き出します。
絵は自動保存されませんのでページを再読み込みすると今まで描いた絵やパレットは初期化されます。

## ショートカット

- `B`　ペン
- `E`　消しゴム
- `I`　スポイトツール
- キャンバス上で`Alt`＋クリック　スポイト
- `Ctrl`＋`Z`　元に戻す
- `Ctrl`＋`Shift`＋`Z` または `Ctrl`＋`Y`　やり直す

Macでは、取り消し・やり直しに `Command` も使えます。
