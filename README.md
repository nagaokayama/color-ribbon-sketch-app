# color ribbon sketch

好きなグラデーションカラーで絵を描ける、ブラウザのお絵かきアプリ。

[アプリを開く](https://nagaokayama.github.io/color-ribbon-sketch-app/)

## カラーセット

- ベース・影・ハイライトと中間色をまとめた5色のセット。
- ベース色の色相・明度・彩度を調整。
- 影とハイライトの色相・明るさ・彩度を調整。
- カラーセットの追加・削除。
- 「影・ハイライトの変更を全セットに適用」で一括調整。
- JSONファイルで全セットを保存・ロード。

ロードすると現在の全カラーセットを置き換えます。

## 描画

- ペン・消しゴムのサイズを1〜100pxで調整。
- ペンの不透明度を0〜100%で調整。
- スポイトでキャンバスの色を取得。
- 最大10操作の取り消し・やり直し。
- キャンバスの拡大・縮小と「画面に合わせる」。拡大後はスクロールで移動。

## 画像の保存

白背景の1024×1024pxのPNGで書き出せます。ファイル名には日時と動物名が付きます。

例　`20261020-0935-otter.png`

絵とカラーセットは自動保存されません。ページを閉じる前に、PNGとカラーセットのJSONをそれぞれ保存してください。

## ショートカット

- `B`　ペン
- `E`　消しゴム
- `I`　スポイト
- `Alt`＋クリック　一時的にスポイト
- `Ctrl`＋`Z`　元に戻す
- `Ctrl`＋`Shift`＋`Z` または `Ctrl`＋`Y`　やり直す

Macでは、取り消し・やり直しに `Command` も使えます。
