# color ribbon sketch

好きなグラデーションカラーで絵を描けるブラウザのお絵かきアプリ。

[アプリを開く](https://nagaokayama.github.io/color-ribbon-sketch-app/)

## カラーセット

- ベース・影・ハイライトと中間色をまとめた5色のセット。
- カラーセットの追加・削除。

## 描画

- ツールはペン、消しゴム、スポイト
- 最大10操作の取り消し・やり直し。


## 画像の保存

1024×1024pxのPNGで書き出します。
絵は自動保存されません。

## ショートカット

- `B`　ペン
- `E`　消しゴム
- `I`　スポイトツール
- キャンバス上で`Alt`＋クリック　スポイト
- `Ctrl`＋`Z`　元に戻す
- `Ctrl`＋`Shift`＋`Z` または `Ctrl`＋`Y`　やり直す

Macでは、取り消し・やり直しに `Command` も使えます。
